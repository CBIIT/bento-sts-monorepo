# MDB-STS prototype

Static interactive prototype for NCI model and terminology exploration.

## Run locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included flows

- Subtle full-bleed DNA video background with slow playback and restrained scroll drift
- Model, node, property, and term search
- Model browsing and definition search options
- Entity detail views with provenance and relationships
- Hierarchical and flat model comparison strategies
- Exact, normalized, CDE ID, and value-set equivalence controls
- Responsive layout, dark mode, reduced-motion support, loading and empty states
